# BRIDGE-000014 — Altium SDK: извлечение 3D-моделей компонентов в Exchange Package

## 1. Цель

Реализовать в Altium Add-in рабочий экспорт 3D-тел компонентов PCB в принятый
Core Exchange Package: `board.snapshot.json`, `models/models.json`,
per-body STEP AP214 assets, manifest и checksums.

Сохранить связь `ComponentInstance.Id → ComponentBody → Asset`; multi-body
компоненты не объединять. Сохранять сырые metadata Altium; не вычислять
неподтверждённые преобразования.

## 3. Ограничения

- Не менять `BoardSnapshot`, Core schema, manifest 1.0.0, старый Writer API.

## 4. Реализация

- Отдельный `AltiumComponentModelReader` + чистые helper-типы.
- Typed iterator `TObjectId.eComponentBodyObject`.
- Owner через `IPCB_PrimitiveHelper.GetState_Component`, model через
  `IPCB_ComponentBodyHelper.GetModel`.
- Identity resolver: UniqueId → SourceUniqueId → уникальный fallback
  (designator + X/Y + rotation + side). Неоднозначность/unknown — fatal.
- `bodyOrdinal` локальный для componentId, по enumeration order, включая тела
  без asset.
- Representation: Generic → generic; Extruded/Cylinder/Sphere → native; иначе
  unknown. `GetEmbed=true` → embedded; procedural без внешних признаков →
  native; `GetEmbed=false` не linked; противоречие → unknown.
- Metadata: `GetOrigin` X/Y IU/mm, Z null; `GetState` raw angles/dz IU/mm;
  `GetRotation` отдельно.
- Per-body `SaveModelToFile` STEP; fallback `ExportToStep`; file nonempty `.step`;
  invalid/partial удалить. Успех — `SdkExport`; иначе body entry остаётся с
  `NotAcquired`.
- Temp `%TEMP%\EcadMcadBridge\model-export\<GUID>\`, cleanup в `finally`.
- Handler: snapshot + model request → recheck → source SHA → Core Writer →
  Core Reader verification. Partial inventory → Warning.
- Version constants `0.4.0`.
