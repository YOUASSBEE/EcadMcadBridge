# BRIDGE-000011 — Controlled 3D Transform Validation

## 1. Цель

Провести контролируемый эксперимент по извлечению и переносу 3D-моделей компонентов из Altium Designer 26 в SOLIDWORKS 2026.

Необходимо экспериментально определить:

1. Как преобразуются координаты исходной STEP-модели в систему координат платы Altium.
2. Как взаимодействуют ориентация исходной STEP-модели, `IPCB_Model.GetState`, `IPCB_Model.GetRotation`, положение и поворот компонента, Top/Bottom.
3. В каких единицах возвращаются углы и `dz`.
4. В каком порядке применяются вращения X/Y/Z.
5. Как реализовано отражение Bottom-side и какова ориентация оси Z.
6. Какие преобразования уже включены в STEP, возвращаемый `ExportToStep` и `SaveModelToFile`.
7. Сохраняются ли геометрия и пространственное положение при импорте STEP и Parasolid X_T в SOLIDWORKS 2026.

**Главный результат:** подтверждённые матрицы преобразования для Generic и Extruded моделей с явным разделением систем координат и ограничений применимости.

Это исследовательская задача. Производственный экспорт, Core schema и SOLIDWORKS Add-in не реализовывать.

## 2. Предыдущие результаты

Изучить PR #9 и документы `.agent/reports/BRIDGE-000010-3d-model-research.md`, `.agent/SDK_API_LEDGER.md`, `.agent/ARCHITECTURE.md`. PR #9 не менять и не мержить.

Уже подтверждено: `IPCB_ComponentBody` через `eComponentBodyObject`; `GetModel`; `GetState` возвращает похожие на углы/смещение значения; `GetRotation` не эквивалентен `GetState` Z; `GetOrigin` — координата начала модели в системе платы; body projection extruded совпадал с локальной STEP bbox без component rotation; generic STEP содержит часть ориентации; Bottom reflection не установлен; STEP AP214/X_T экспорт подтверждён, импорт в SOLIDWORKS не проверялся. Основные вопросы: V-27, V-29, V-30, V-33.

Altium Designer 26.12.2.9, SDK 4.0.1, .NET SDK 10, C# typed API. Запрещены DelphiScript, Legacy API, reflection, `dynamic`, ручной парсинг `.PcbDoc`. Не менять пользовательские PCB, production Core/Exchange Package, не создавать SOLIDWORKS Add-in, не менять архитектуру без решения. ## 4. Контрольные геометрии

### 4.1 Generic STEP

Создать в SOLIDWORKS 2026 асимметричную деталь: основание `12 × 7 × 1 mm`, выступ `2 × 3 × 2 mm` в положительной четверти XY со смещением, сквозное отверстие `1 mm`, вся геометрия в положительном октанте, origin в нижнем углу основания. Зафиксировать систему координат, характерные точки, объём, SHA-256 и формат экспорта. Сохранить исходную деталь и STEP вне Git.

### 4.2 Native Extruded

Создать в Altium отдельную Extruded-модель с L-профилем `(0,0),(12,0),(12,2),(5,2),(5,7),(0,7)`, высота `3 mm`, origin профиля `(0,0)`. Зафиксировать точную геометрию и размеры.

## 5. Матрица размещения

Создать изолированную тестовую PCB. Для каждой модели — Top/Bottom × component rotation 0/90/180/270, минимум 16 экземпляров, разные координаты, исходная ориентация модели нулевая, если Altium позволяет. Дополнительно Generic model state: G-RX90 (90/0/0/0), G-RY90 (0/90/0/0), G-RZ90 (0/0/90/0), G-XYZ (30/45/60/+1mm), G-XYZ-NEG (30/45/60/-1mm). Если параметр нельзя задать, зафиксировать ограничение, не имитировать.

Проверить `dz`: 0, +1.0, -1.0 mm; при возможности ±0.5/+2.0. Записывать настройку и фактический `GetState`, не считать единицы доказанными без проверки.

## 6. Сбор данных

Для каждого экземпляра: Component designator, X/Y, rotation, layer, side, flip/mirror API; ComponentBody parent, `GetGeometricPolygon`, `GetBodyProjection`, standoff, overall, bounding rectangle, orientation state; Model source/type/embed/file basename/data size/checksum/origin/state/rotation. Для линейных значений raw IU + mm + формула; углы raw + проверенный смысл. Сравнить GetState/GetRotation, GetOrigin с исходным origin, body projection с геометрией, component placement с Altium 3D Layout.

## 7. Матрицы преобразования

Определить S (STEP), M (Altium Model), C (component), B (board), W (MCAD) в right-handed 4×4, column vectors, `T_A_B` — B→A, единицы явно. Для Generic/Extruded отдельно: source model, model state, component placement, Bottom reflection, Z, итог в board. Не предполагать заранее `T_board_component × T_model`. Для Bottom проверить ось отражения, отражение геометрии/ориентации, знак Z, влияние GetState, GetOrigin Top/Bottom, зависимость от `GetFlippedOnLayer`. Reflection не подменять поворотом 180°. Если формулы разные — дать две с областью применимости. Если не удалось — V-27/V-29/V-30 открыты.

## 8. Экспорт

Для representative: STEP `ExportToStep`, STEP `ComponentBody.SaveModelToFile`, X_T `SaveModelToFile`. Минимум Generic Top 0/90, Generic Bottom 0, Generic combined 30/45/60, Extruded Top 0, Extruded Bottom 0. Фиксировать SHA-256, размер, API, экземпляр, формат, импорт. Сравнить геометрию, bbox, origin, встроенную ориентацию, component placement, Bottom reflection, Z. SHA может отличаться из-за timestamp.

## 9. SOLIDWORKS 2026

Импорт representative STEP/X_T штатным импортом и измерение: без ошибок, B-Rep, число тел, bbox X/Y/Z, объём, положение выступа/отверстия, ориентация осей, origin, Z. Сравнить STEP/X_T/исходник. Отдельно проверить Bottom reflection. Скриншоты измерений/3D-видов сохранить вне Git. Успешный импорт не доказывает правильное расположение относительно платы — проверять отдельно.

## 10. Допуски
