# BRIDGE-000015 — SOLIDWORKS 2026: STEP import и создание нативных деталей

## 1. Цель

Создать отдельный SOLIDWORKS backend, который читает Core Exchange Package,
импортирует уникальные STEP AP214 assets через typed SOLIDWORKS API, сохраняет
native `.SLDPRT`, сохраняет соответствия `ComponentId → BodyOrdinal → AssetPath →
SLDPRT`, проверяет assembly API на двух деталях и подтверждает операции на
SOLIDWORKS 2026.

Это backend/прототип, не полноценный Add-in. Placement ECAD-компонентов,
`T_B_S`, Bottom, Euler composition и SOLIDWORKS Add-in registration не входят.

## 5. STEP import и native SLDPRT

- `GetImportFileData` → `MapConfigurationData=false`.
- `LoadFile4`, проверить тип part/assembly, solid bodies через
  `PartDoc.GetBodies2`.
- `SaveAs3` (current version, silent) в `.SLDPRT`; проверить errors/warnings,
  файл и размер.
- Закрыть импортированный документ, повторно открыть `OpenDoc6`, сравнить body
  counts.
- STEP, импортированный как assembly, сохранять как native part; не терять
  geometry. Dedup: один unique asset → одна native part, все body refs ссылаются
  на неё.
